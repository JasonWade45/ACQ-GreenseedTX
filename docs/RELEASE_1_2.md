# Acquisitions Assistant — Unified 1.2

One working local-first seller-acquisitions application, combining compatible GitHub features with the complete reviewed 1.1 core. Prebuilt UI included: Windows runtime needs Python, not Node/WSL.

## Included

- Database-backed dashboard, seller profiles/search, daily queues, local tasks/appointments/reports/audit and conservative read-only CRM sync.
- Reviewed CSV/XLSX mapping/import/deduplication, richer property extraction, compound/address-only prospects and explicitly approved fill-empty enrichment.
- Persistent local preparation/checklists, grounded property research criteria and exact subject address; no fabricated sold comps or appraisal.
- Backup-first bridge between the incompatible GitHub UUID database and delivered integer/Alembic database, explicit separate/link/skip review, stable identities and preserved private history.
- Optional Groq with redacted preview and approval **for every request**, private backend settings, independent output review and copy-only drafts.
- Responsive English UI, native Windows start/update/merge helpers, Arabic guide, source/tests/migrations/QA evidence and SHA-256 file manifest.

## Safety and actual limits

No seller send/SMS/email/call endpoint or job; no CRM create/edit/delete/status/note write; no automatic cloud batches. Company DBs, keys and private runtime/password files are not included or uploaded.
