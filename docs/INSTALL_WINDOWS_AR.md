# البرنامج على جهازك — تنصيب بدبل كليك، بلا PowerShell

**الإصدار 1.3.1.** من هنا فصاعدًا لا تحتاج فتح نافذة أوامر، ولا تثبيت Python، ولا فكّ
ضغط ملف، ولا تذكّر مسار. البرنامج ملف تنصيب واحد، واختصار على سطح المكتب.

---

## 1. التنصيب (مرة واحدة)

1. نزّل **`ACQ-Setup-1.3.1.exe`** من صفحة الإصدارات.
2. دبل كليك عليه.
3. إن ظهرت شاشة زرقاء من ويندوز تقول **«Windows protected your PC»**:
   اضغط **More info** ثم **Run anyway**.
   > هذا لأن الملف غير موقّع بشهادة رقمية (تكلفتها سنوية ومدفوعة). الملف نفسه سليم،
   > وهذه الشاشة تظهر **مرة واحدة فقط** لكل نسخة.
4. اضغط **Next** ثم **Install** ثم **Finish**.

انتهى. ستجد:

| العنصر | مكانه |
|---|---|
| الأيقونة على سطح المكتب | `Acquisitions Assistant` |
| في قائمة ابدأ | `Acquisitions Assistant` (مع اختصار مجلد البيانات وإلغاء التنصيب) |
| البرنامج نفسه | `%LOCALAPPDATA%\Programs\AcquisitionsAssistant\ACQ.exe` |
| **بياناتك** | `%LOCALAPPDATA%\AcquisitionsAssistant\` |

يمكنك اختيار **«Start Acquisitions Assistant automatically when I sign in»** أثناء
التنصيب إن أردت أن يعمل مع بداية الويندوز.

**لا يحتاج صلاحيات مدير، ولا يفتح منفذًا على الإنترنت.**

---

## 2. الاستخدام اليومي

دبل كليك على الأيقونة. تُفتح **نافذة البرنامج** (ليست تبويب متصفح)، وداخلها الواجهة كاملة.

- إغلاق النافذة يوقف البرنامج.
- الضغط على الأيقونة مرة ثانية أثناء عمله **لا يشغّل نسخة أخرى** — يفتح النافذة الموجودة.
- أول تشغيل يُنشئ كلمة مرور قوية تلقائيًا، وتُحفظ في ملف الإعدادات عندك.

### من الموبايل على نفس الواي فاي

داخل البرنامج: زر **«Scan from phone»** يعرض رمز QR. امسحه بكاميرا الموبايل، أو اكتب
العنوان الظاهر (`http://192.168.x.x:8010`) وأدخل كلمة المرور من زر **«Show»**.

إن لم يفتح الموبايل الصفحة، افتح PowerShell كمسؤول **مرة واحدة** ونفّذ:

```
netsh advfirewall firewall add rule name="Acquisitions Assistant" dir=in action=allow protocol=TCP localport=8010
```

## 3. أين بياناتك، وماذا يحدث عند التحديث

كل شيء في مجلد واحد:

```
%LOCALAPPDATA%\AcquisitionsAssistant\
├── data\acquisitions.db      ← كل الملاك والنشاطات والمقارنات
├── data\backups\             ← النسخ الاحتياطية الليلية
├── .env                      ← كلمة المرور، وإعدادات Groq وREsimpli إذا أضفتها
└── logs\
```

هذا المجلد **خارج** مجلد البرنامج. معنى ذلك:

- تنصيب نسخة أحدث يستبدل البرنامج فقط، وبياناتك تبقى كما هي.
- إعادة التنصيب أو الإصلاح لا تمسّ البيانات.
- إلغاء التنصيب **يسألك**: «هل تُبقي بياناتك؟» — اختر Yes لتفتح بها النسخة القادمة.

للوصول السريع: من قائمة ابدأ → **Open data folder**.

**مهم:** `.env` يحتوي مفتاح Groq الخاص بك إن أضفته. لا تنسخ هذا المجلد إلى أي مكان
مشترك ولا ترفعه على الإنترنت.

---

## 4. نسخة محمولة (USB) — اختياري

لو أردت أن تكون البيانات بجانب البرنامج بدل `LOCALAPPDATA`:

```
set ACQ_PORTABLE=1
ACQ.exe
```

حينها تُحفظ البيانات في مجلد `ACQ-data` بجانب البرنامج، فتنتقل مع الفلاشة.

---

## 5. الانتقال من النسخة القديمة (ZIP + START-ACQ.cmd)

لا تحتاج فعل شيء يدويًا:

- **لو كنت تعمل بالـZIP:** افتح المجلد القديم كما هو — البرنامج يستخدم نفس مكان
  البيانات السابق، فكل ملاكك موجودون.
- **لو نصّبت البرنامج الجديد:** عند أول تشغيل يبحث عن قاعدة بيانات قديمة في مجلد
  البرنامج وينسخها إلى مجلد البيانات الجديد، **ولا يحذف الأصل**.
  (يُترك ملف `.adopted-from-program-folder` كدليل على أن النسخ حدث مرة واحدة.)

## 6. لمن يريد بناء الملف بنفسه (مجانًا)

البناء الرسمي يجري على سيرفر GitHub الويندوزي المجاني:

`.github/workflows/windows-app.yml` — يعمل تلقائيًا عند كل وسم `v*`، ويرفع
`ACQ.exe` و`ACQ-Setup-*.exe` كملفات قابلة للتنزيل، ويجرّب البرنامج فعليًا قبل
أن يسلّمه (يشغّله، ينتظر `/api/health`، يفتح الصفحة، يتأكد أن القاعدة `.env`
أُنشئت، ويتأكد أن نسخة ثانية لا تشغّل خادمًا ثانيًا).

أو على جهاز ويندوز عندك:

```
python scripts/build_windows.py
```

يحتاج Python 3.11 وNode.js و[Inno Setup](https://jrsoftware.org/isdl.php) (كلها مجانية).

---

## 7. ما لا يفعله البرنامج

- لا يرسل SMS أو بريدًا أو مكالمات.
- لا يرفع بياناتك إلى أي خدمة إلا بموافقتك على معاينة مُخفَّاة قبل كل طلب.
- لا يعمل في الخلفية بلا نافذة، ولا يبدأ مع الويندوز إلا إن اخترت ذلك بنفسك.
- لا يحتاج إنترنت للتشغيل المحلي.
