# النظام الجاهز — Acquisitions Assistant AI 1.2.8

**آخر تحديث: 28 أكتوبر 2026 (Africa/Cairo).** هذا هو المستند العربي الأول: يقول ما هو
النظام، وكيف تشغّله، وما الذي **لا** يشمله. لا يحتاج أي خطوة إلى ويندوز من أجل النشر.

---

## 1. الخلاصة في سطر واحد

برنامج **يعمل على جهازك**، بياناته في ملف واحد على قرصك، تفتحه من نفس الجهاز أو من
الموبايل عبر الواي فاي بكلمة مرور، وله نسخ احتياطي تلقائي مُتحقَّق منه. وإن أردت لاحقًا
نشره على الإنترنت فالمسار Linux فقط.

| البند | الحالة |
|---|---|
| التشغيل | `START-ACQ.cmd` (ويندوز) أو `./start-acq.sh` (لينكس/ماك) |
| الوصول من الموبايل | نفس الشبكة + كلمة مرور تُولَّد تلقائيًا + QR |
| قاعدة البيانات | SQLite محلية: **20 جدولًا**، رأس `0a6d91cf17b2` |
| النسخ الاحتياطي | تلقائي كل ليلة + يدوي من الواجهة، مع فحص سلامة |
| الجلسات | 12 ساعة، مع خروج فوري على الخادم وإلغاء كل الأجهزة |
| اختبارات الخلفية | **250 نجح + 1 متخطّى** (آخر تشغيل) |
| اختبارات الواجهة | **21 نجح من 21**، وبناء TypeScript نظيف |
| النشر على الإنترنت | Linux فقط — `deploy/install.sh` أو Render |

## 2. ابدأ الآن (5 دقائق)

1. فكّ ضغط الحزمة، وادخل مجلد `acquisitions-assistant`.
2. شغّل:
   - **ويندوز:** دبل كليك على `START-ACQ.cmd`.
   - **لينكس/ماك:** `./start-acq.sh`.
3. اقرأ ما طُبع: عنوان الجهاز، عنوان الشبكة، كلمة المرور، ورمز QR.
4. افتح العنوان من الموبايل، اكتب كلمة المرور، وابدأ.

**التفاصيل الكاملة:** [`DESKTOP_LAN_AR.md`](DESKTOP_LAN_AR.md).

## 3. أول استخدام

قاعدة البيانات الجديدة **فارغة تمامًا** — لا يوجد أي عميل تجريبي مخفي.

1. **Import Center** → استورد ملف CSV/XLSX لبيانات حقيقية راجعتها.
2. عيّن معنى كل حالة مصدر صراحة؛ الحالات المجهولة تبقى **«Unmapped source status»**
   ولا تُعتبر «New» تلقائيًا.
3. خذ نسخة احتياطية من **الإعدادات → Runtime & backups** قبل أي استيراد كبير.
4. استخدم **Daily Follow-ups** والملفات لتسجيل ما حدث فعلًا، لا للتواصل الآلي.

> **لا يوجد أي تواصل تلقائي.** لا رسائل ولا بريد ولا اتصال. المسودّات للمراجعة والنسخ
> اليدوي فقط، ومزامنة CRM للقراءة فقط.

## 4. القاعدتان القديمتان (1.1 وGitHub)

هما مختلفتان في المخطط، **ولا تُستبدل إحداهما بالأخرى أبدًا**.

الدمج يجري على جهاز ويندوز عبر أدوات مؤرشفة في [`legacy/windows`](../legacy/windows/README.md):

1. أغلق كل النسخ القديمة.
2. `legacy\windows\UPDATE-WINDOWS.cmd` على جذر 1.1 القديم.
3. `legacy\windows\MERGE-WORKSPACES.cmd` واختر قاعدة GitHub القديمة.
4. `START-ACQ.cmd` → **Import Center** → راجع كل شخص واعتمد فصل/ربط/تجاهل صراحة.

الخطوات التفصيلية وحدودها: [`UNIFIED_MERGE.md`](UNIFIED_MERGE.md). **لا ترفع قاعدة شركة
أو مفتاحًا إلى GitHub أو المحادثة.**

## 5. النسخ الاحتياطي والاسترجاع

- نسخة **ليلية** في `data/backups/`، آخر 7 محفوظة، واليدوية لا تُمسح.
- كل نسخة تُفحص بـ`integrity_check` و`foreign_key_check` وتُخرج من وضع WAL قبل تسميتها،
  وأي نسخة فاشلة تُحذف ولا تُترك.
- من الواجهة: أنشئ، نزّل، احذف (بتأكيد صريح).

الاسترجاع **والبرنامج مغلق**:

```bash
.venv/bin/python scripts/manage.py backup --output backups/before-restore.db
.venv/bin/python scripts/manage.py restore --input data/backups/<الاسم>.db --confirm "RESTORE LOCAL DATABASE"
```

> على ويندوز استبدل `.venv/bin/python` بـ`.venv\Scripts\python.exe`.

## 7. ما تم التحقق منه فعلًا

| البند | النتيجة |
|---|---|
| اختبارات الخلفية | **250 نجح + 1 متخطّى**، `ruff` نظيف |
| اختبارات الواجهة | 21 نجح، `tsc -b` + `vite build` نظيفان |
| صورة Docker | تُبنى وتعمل في CI: ترفض كلمة مرور ضعيفة، 401 بلا توكن، 200 بعده |
| الحزمة | تُبنى ببصمة، وتُشغَّل من مجلد فيه مسافة: صحة/صفحة/دخول/API كلها 200 |
| `install.sh` | `--help` يعمل عبر الأنبوب، `--dry-run` كامل، `--no-https` بمنفذ مباشر |
| النسخة الاحتياطية | مُختبرة بما فيها كتابة WAL غير مُدمَجة: تظهر كاملة داخل الملف ولا تُترك ملفات جانبية |

**لم يُتحقق منه:** تشغيل على ويندوز حقيقي، فتح المنفذ من موبايل فعلي، سيرفر Linux حقيقي
بنطاق وHTTPS، وقاعدتا الشركة الحقيقيتان. هذه تحتاج جهازك وبياناتك.
