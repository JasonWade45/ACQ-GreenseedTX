## 2. ما تم دمجه بالدليل (مقارنة Drive ↔ المستودع)

1. **مجلد `ACQ-GreenseedTX-unified-v1.2.1` مطابق تمامًا للمستودع الحالي**: 145 ملفًا،
   ونجحت كل الملفات الـ145 في مطابقة `RELEASE_FILES.sha256`، ونفس العناصر الـ24 في الجذر.
2. **مستندات نسخة 1.2 (24 أكتوبر) مطابقة بايت ببايت** لمستندات 1.2.1 (تم التحقق من
   بصمات MD5 لكل ملفات `docs/`)، أي أن 1.2.1 لم تُغيّر أي مستند بل **أضافت** ثلاث وثائق
   (`RELEASE_1_2_1.md`, `PRIVATE_DATABASE_BACKUP.md`, تحديث `VERIFICATION.md`).
3. **نسخة `acquisitions-assistant-source` (21 أكتوبر)** لا تحتوي أي ملف برمجي غير موجود
   في 1.2.1؛ الزائد عندها هو مخرجات بناء فقط: `.venv/`، و`data/acquisitions.db` (قاعدة
   قديمة: 17 جدولًا، **صفر** عملاء)، و`npm-audit-initial.json`.
4. **حزمة `ACQ-GreenseedTX-publish-kit` كانت لا تزال 1.1** (bundle قديم 4.95 م.ب) —
   تم إنتاج بديل 1.2.1 لها (القسم 6).

**النتيجة:** لا توجد تحسينات برمجية مفقودة تحتاج دمجًا؛ 1.2.1 كانت ولا تزال الاتحاد
الكامل. العمل الحقيقي كان التحقق، والبيانات، والتنظيم، والحزمة النهائية.

## 3. البيانات: ما هو موجود وما هو غير موجود

- **لا توجد قاعدة بيانات الشركة الحقيقية في مجلد Drive**، لا نسخة GitHub UUID
  (`backend/acquisitions.db`) ولا نسخة التسليم 1.1 (`data/acquisitions.db`). لذلك لا
  يمكن — ولا يصح — أن تُدمج بيانات حقيقية لم تصل أصلًا.
- القاعدة الوحيدة الموجودة في المجلد القديم هي `data/acquisitions.db` القديمة **الفارغة**
  (17 جدولًا، 0 عملاء). لا قيمة بيانات فيها.
- النظام هنا أنشأ **قاعدة نظيفة كاملة** على المخطط الحالي (20 جدولًا) جاهزة للاستخدام.
- لأغراض **المعاينة فقط** أُنشئت `data/demo.db` تحتوي 6 عملاء **خياليين** جرى استيرادهم
  من `examples/sample-seller-leads.csv` عبر واجهة الاستيراد الحقيقية. هذه ليست بيانات
  شركة، وليست داخل حزمة الإصدار، ولا تدخل قاعدة العمل.
- عند تشغيل 1.2.1 على جهازك تُنشأ `data/acquisitions.db` نظيفة تلقائيًا ثم تُدمج فيها
  قاعدتاك عبر `MERGE-WORKSPACES` بموافقتك الصريحة على كل صف.

## 4. دمج قاعدتي الشركة الحقيقيتين (على جهازك أنت)

الترتيب الآمن المعتمد في المشروع:

1. **أوقف أي تطبيق قديم** يعمل.
2. **`UPLOAD-DATABASES.cmd`** — نسخة احتياطية مشفّرة (scrypt + AES-256-GCM) للقاعدتين
   إلى المستودع الخاص `JasonWade45/acq-company-database-backups`. كلمة المرور تُطلب محليًا
   ولا تُرفع أبدًا.
3. **`UPDATE-WINDOWS.cmd`** — حدّد جذر التسليم 1.1 القديم. يأخذ نسخة استرداد تلقائية قبل
   أي ترحيل.
4. **`MERGE-WORKSPACES.cmd`** — اختر قاعدة GitHub `backend/acquisitions.db` كمصدر. تُعرض
   المرشحات والتعارضات أولًا، ثم تقرر لكل شخص: **منفصل / ربط / تخطٍّ**. لا دمج تلقائي.
5. **`START-WINDOWS.cmd`** → **Import Center** → راجع كل قرار معلّق واعتمده صراحة.
6. احتفظ بالأصلين والنسخ الاحتياطية. **لا تنسخ قاعدة فوق الأخرى أبدًا** — المخططات مختلفة.

> `backend/acquisitions.db` بصيغة UUID القديمة **ليست** ملف استعادة متوافق مع قاعدة 1.2.
> الحارس يرفض تطبيق الترحيلات عليها؛ استخدم الجسر المراجع لا نسخ SQL.

## 5. تشغيل النظام

### على Windows (الطريقة الموصى بها)

1. فك ضغط الحزمة `ACQ-GreenseedTX-v1.2.1.zip` (الواجهة المبنية داخلها — **لا تحتاج Node**).
2. انقر مزدوجًا على **`START-WINDOWS.cmd`**.
3. اتبع `START_HERE_WINDOWS_AR.md` (دليل عربي مفصّل بالخطوات والصور النصية).

### على Linux / macOS (هذه البيئة)

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements-lock.txt
cd frontend && npm ci && npm run build && cd ..
APP_ACCESS_PASSWORD='كلمة-مرور-قوية-12-حرفًا-على-الأقل' .venv/bin/python scripts/run.py
```

- الافتراضي `127.0.0.1:8000`. أي ربط خارج harness المحلي **يتطلب** كلمة مرور ≥ 12 حرفًا.
- الواجهة والـAPI على نفس الأصل (same-origin)، ولا يوجد CDN أو اعتماد على خدمة سحابية.
- كلمة المرور في المعاينة التي شغّلتها هنا: `Greenseed-TX-2026!` (غيّرها دائمًا في تشغيلك).

**التحقق السريع أن النظام سليم:**

```bash
curl localhost:8000/api/health          # {"status":"ok", ...}
curl -o /dev/null -w '%{http_code}\n' localhost:8000/api/leads   # 401 قبل الدخول
```

## 7. الأمان والقيود (اقرأها قبل الاستخدام التجاري)

- **لا يوجد أي تواصل تلقائي مع البائع**: لا SMS ولا بريد ولا مكالمات ولا dialer. الإعداد
  والمسودات لا تسجّل تواصلًا، والمشغّل البشري يستخدم وسيلة معتمدة خارج النظام.
- **REsimpli للقراءة فقط**: لا إنشاء/تعديل/حذف/ملاحظات، ولا تفعيل تلقائي جدولةً أو عند
  بدء التشغيل. تعيين الحقول الحقيقي يحتاج تحققًا على حسابك.
- **DNC لا يُرفع محليًا**، والمجهول ليس تصريحًا، و«مراجَع-واضح» ليس شهادة إذن قانوني.
- **Groq/Ollama اختياريان** وخلف بوابات موافقة وانتهاء صلاحية وبصمة مصدر، والمخرجات
  السحابية اقتراح يُراجع ثانيًا قبل حفظه، والمسودات للنسخ فقط.
- **مفاتيح المزوّدين** لا تُكتب في الشيفرة ولا تُرسل في المحادثة. أدخل بدائل مُدوّرة محليًا.
- **قواعد SQLite والنسخ الاحتياطية ملفات خاصة غير مشفّرة على القرص** — احمِ صلاحيات
  المجلد وفعّل تشفير القرص. ليست خزنة أسرار.
- **حدود غير متحققة هنا:** تشغيل سكربتات Windows الأصلية، حساب REsimpli الحقيقي، إكمال
  Groq فعلي، واستنتاج Ollama. المرور على المحاكيات لا يُثبت جاهزية الحساب.
- **بيانات Drive:** المجلد مشترك بصلاحية «أي شخص لديه الرابط — قراءة». لا تضع فيه قاعدة
  شركة أو مفتاحًا أو كلمة مرور. تم إخراج القاعدة القديمة من المجلد المشترك لهذا السبب.
